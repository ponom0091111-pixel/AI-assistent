# AI-ассистенты для монтажа видео

Набор системных промптов для создания коротких вертикальных роликов (Reels, Shorts, TikTok). Каждый файл в `assistants/` вставляется целиком как системный промпт (инструкция) в Claude, ChatGPT, Project или GPTs.

| Ассистент | Файл | Что делает |
|---|---|---|
| Аналитик референсов | `assistants/01-reference-analyst.md` | Разбирает чужой ролик: планы, склейки, текст, шрифты, цвета |
| Генератор промтов | `assistants/02-video-prompt-generator.md` | Пишет промты для Sora / Veo / Kling / Runway |
| Монтажёр | `assistants/03-editor.md` | Даёт задание на монтаж и пошаговую инструкцию для CapCut, VN, Premiere |
| Сценарист серии | `assistants/04-scriptwriter.md` | Придумывает темы, тексты на экран и контент-план |

## Как работать
1. **Аналитик:** загрузите референс и получите разбор.
2. **Сценарист:** придумайте свою тему и текст на экране в том же формате.
3. **Генератор промтов:** получите промт и сгенерируйте футаж, если не снимаете сами.
4. **Монтажёр:** соберите ролик и сохраните его как шаблон для серии.

## Референсы
- `references/reels-78.md` — «Плюсы процедур в сравнении»: разбор ролика и два готовых промта (генерация и монтаж). Перенесено из сессии «Промт для видео с подобным монтажом».
