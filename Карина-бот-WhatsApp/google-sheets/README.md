# Google Таблица для бота Карины

В таблице два вида листов:

- **Расписание на месяц** (например «Октябрь 2026»). Каждая строка — слот 30 минут:
  `Дата | День недели | Начало | Окончание | ФИО | Процедура | ИИН | Телефон | Источник | Статус записи | Создано | Статус слота`.
  «Источник» — откуда пришёл клиент: Instagram / Facebook — платная реклама или бесплатно, 2ГИС, Рекомендация, Другое.
  Пн–Пт 11:00–19:30, Сб 11:00–14:30, воскресенья нет. «Статус слота» считается сам:
  «Свободно» / «Занято».
- **Клиенты** — журнал всех событий от бота (записался, думает, отложил визит, перенёс, отменил).

Бот записывает только **первичную диагностику ЖКТ** — 1 слот (30 минут).
Повторный приём (1 час) администратор вносит вручную в 2 слота подряд.

## Файлы

- `Расписание_Октябрь_2026.xlsx` — готовое расписание на октябрь 2026 (можно сразу загрузить в Google Таблицы).
- `Code.gs` — скрипт: бот пишет в слоты, освобождает их при отмене и узнаёт свободное время;
  в таблице появляется меню «Расписание» для создания листов на следующие месяцы.

## Настройка (один раз)

1. Google Диск → **Создать → Загрузить файл** → `Расписание_Октябрь_2026.xlsx`.
   Откройте его и выберите **Файл → Сохранить как таблицу Google**.
2. **Файл → Настройки → Часовой пояс: (GMT+05:00) Алматы.** Доступ к таблице — только у вас.
3. **Расширения → Apps Script.** Удалите всё и вставьте код из `Code.gs`.
   В «Настройках проекта» (шестерёнка) тоже поставьте часовой пояс Алматы.
4. В строке `const SECRET = '...'` придумайте свой секретный ключ.
5. **Развернуть → Новое развертывание → Веб-приложение.** Выполнять как: **Я**, доступ: **Все**.
   Разрешите доступ и скопируйте URL веб-приложения.
6. Обновите страницу таблицы — появится меню **«Расписание»**. В конце месяца нажмите
   «Создать лист на следующий месяц».

## Настройка платформы бота (SaleBot, LeadTeh и т. п.)

**Свободное время для бота.** Перед ответом ИИ сделайте GET-запрос
`URL?secret=ваш_ключ&days=7` и подставьте список `free` в переменную `{{свободные_слоты}}` промпта.

**Запись в таблицу.** После ответа ИИ:
1. найдите в ответе текст между `<crm>` и `</crm>`;
2. удалите этот блок из сообщения клиенту;
3. отправьте POST-запрос на URL, тело — JSON из блока плюс `"secret"`:
   ```json
   {"secret": "ваш ключ", "ФИО": "Пономарева Наталья Сергеевна", "ИИН": "123456789012",
    "Телефон": "+77770000000", "Дата визита": "10.10.2026 12:30", "Напомнить": "", "Статус": "Записан"}
   ```

Что делает скрипт по статусу:
- **Бронь** — клиент выбрал время: слот сразу блокируется (держится 60 минут до оплаты).
- **Записан** — оплата получена: в слот пишутся ФИО, процедура, ИИН, телефон.
- **Перенёс запись** — проверяет, что новое время свободно, освобождает старый слот и занимает новый.
- У каждого клиента (по телефону) в расписании всегда одна запись: при любой новой брони, записи или переносе старая удаляется.
- Если время уже занято другим клиентом — ответ `{"ok":false,"error":"slot_busy"}`; передайте его боту
  в переменную `{{результат_записи}}`, и Карина предложит другое время.
- **Отменил запись** — освобождает слот.
- Любой статус — добавляет строку в лист «Клиенты».
