# Карина — бот на WhatsApp и агент

ИИ-консультант центра аппаратного оздоровления **New Forms** (Алматы). Карина общается
с клиентами в WhatsApp, проверяет противопоказания и записывает на первичный Check-up ЖКТ
по акции (6 000 ₸ вместо 15 000 ₸, бронь 1 000 ₸ через Kaspi).

## Состав проекта

| Файл | Что это |
|---|---|
| `prompt.md` | Готовый системный промпт Карины — вставляется в платформу бота (SaleBot, LeadTeh и др.) |
| `Промпт_Карина_WhatsApp.txt` | Тот же промпт в формате .txt — открывается Блокнотом, удобно копировать |
| `google-sheets/Расписание_Октябрь_2026.xlsx` | Расписание на октябрь 2026: слоты по 30 минут, Пн–Пт 11:00–19:30, Сб 11:00–14:30 |
| `google-sheets/Code.gs` | Скрипт Google Таблицы: запись клиентов в слоты, перенос/отмена, свободное время для бота, листы на новые месяцы |
| `google-sheets/README.md` | Пошаговая настройка таблицы и связки с платформой бота |

## Как запустить

1. Загрузить расписание в Google Таблицу и установить скрипт — `google-sheets/README.md`.
2. Подключить WhatsApp Business API к платформе бота и вставить `prompt.md` как системный промпт.
3. Связать переменные `{{...}}` из конца промпта с переменными платформы.
4. Настроить: вырезать блок `<crm>…</crm>` из ответа ИИ и отправлять его POST-запросом в скрипт таблицы.
5. Вписать правило возврата брони при отмене (`{{правило_возврата_брони}}`).
6. Пройти тестовый диалог от приветствия до записи и проверить, что клиент появился в таблице.
