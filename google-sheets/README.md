# Google Таблица для бота Карины

Таблица заполняется автоматически: бот пишет в конце ответа служебный блок
`<crm>{...}</crm>`, платформа вырезает его из сообщения клиенту и отправляет
JSON сюда. Скрипт добавляет новую строку.

Колонки: Дата и время | ФИО | ИИН | Телефон | Дата визита | Напомнить | Статус

## Настройка (один раз, ~10 минут)

1. Создайте новую Google Таблицу. Доступ — только у владельца (в ней ИИН и ФИО).
2. В таблице: **Расширения → Apps Script**. Удалите всё и вставьте код из `Code.gs`.
3. В строке `const SECRET = '...'` придумайте свой секретный ключ (любой длинный набор букв и цифр).
4. **Развернуть → Новое развертывание → Тип: Веб-приложение.**
   - Выполнять как: **Я**
   - Доступ: **Все**
   Нажмите «Развернуть», разрешите доступ и скопируйте URL веб-приложения.
5. На платформе бота (SaleBot, LeadTeh и т. п.) после ответа ИИ:
   - найдите в ответе текст между `<crm>` и `</crm>`;
   - удалите этот блок из сообщения клиенту;
   - отправьте POST-запрос (блок «Webhook» / «HTTP-запрос») на URL из шага 4.
     Тело — JSON из блока, плюс поле `"secret": "ваш ключ"`, например:
     ```json
     {"secret": "ваш ключ", "ФИО": "Пономарева Наталья Сергеевна", "ИИН": "123456789012",
      "Телефон": "+77770000000", "Дата визита": "10.10.2026 12:30", "Напомнить": "", "Статус": "Записан"}
     ```
6. Проверьте: пройдите диалог до записи — в таблице появится лист «Клиенты» с новой строкой.
